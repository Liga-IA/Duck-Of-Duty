# Duck of Duty

## Windows (PowerShell)

```powershell
cd caminho\para\Duck-Of-Duty
py -m http.server 8000
```

Abra no navegador: http://localhost:8000

## Ubuntu (Terminal)

```bash
cd /caminho/para/Duck-Of-Duty
python3 -m http.server 8000
```

Abra no navegador: http://localhost:8000

Permita o acesso à câmera quando o navegador solicitar. Para encerrar o servidor, pressione `Ctrl+C` no terminal.
